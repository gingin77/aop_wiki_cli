   - `@ids_from_fulltext: [1944, 389, 388, 618, 445, 2078, 875, 2098, 2371, 195, 201, 757]`

## Details on Event First Collections Configs

AOP collection configs are stored in `configs/event_first_collections.py`.

Each config must define:

- **input_term**: Term for naming outputs and logging
- **event_title_filter**: List of event IDs with term in title
- **event_ft_filter**: List of event IDs with term in full text (can be None)
- **output_config**: Dict with `ke_file_name`, `aop_file_name`, and `logger_name`

**Available configs:**

- `DEPRESSION_CONFIG`: Depression-related events
- `PARKINSON_CONFIG`: Parkinson's-related events

### Creating New Collection Configs

1. Add a new config to `configs/event_first_collections.py`
2. Define all required fields (see existing configs as examples)
3. Use with: `uv run python cli.py collect-entities-for-events -c YOUR_CONFIG`
